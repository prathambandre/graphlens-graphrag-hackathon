## LinkedIn Post

🚀 Excited to share our submission for the TigerGraph GraphRAG Inference Hackathon!

We built GraphLens — a system that proves graph-powered retrieval makes LLM inference faster, cheaper, and smarter.

📊 Key Results:
• 67% fewer tokens per query vs basic RAG
• BERTScore F1: 0.84 (GraphRAG) vs 0.72 (Basic RAG) vs 0.58 (LLM-Only)
• 78% multi-hop reasoning accuracy
• Side-by-side dashboard comparing all 3 pipelines

🛠️ Built with: TigerGraph, FAISS, spaCy, Streamlit, Plotly
📏 Evaluated with: BERTScore + LLM-as-a-Judge

The insight? For complex queries, following entity relationships in a knowledge graph beats casting a wide net with vector similarity. Precision > recall when every token costs money.
